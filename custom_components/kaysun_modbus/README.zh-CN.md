# Kaysun GW-Modbus(A) Home Assistant 集成

简体中文 | [English](README.md)

这是一个用于 Kaysun `GW-MOD(A)` / `K05-MODBUS A` 网关的本地
Modbus TCP 集成。寄存器定义依据 `MD20U-014A-ZH` A.0 版手册实现。

本集成使用 Home Assistant 内置 Modbus 集成提供的 PyModbus 版本，避免不同
Home Assistant 版本之间的依赖冲突，包括 2026.4 使用的 `pymodbus 3.11` 和
2026.7 使用的 `pymodbus 3.13`。

## 功能

- 支持通过界面添加和修改配置，无需编写 YAML。
- 室内机地址范围为 `0-63`。针对当前 32 台室内机，默认地址为 `0-31`；也支持
  `0-7,10,12-31` 这类不连续地址。
- 根据输入寄存器 `30014 + n*16` 自动识别 VRF 和 HTHM 室内机。
- VRF 空调实体支持关闭、送风、制冷、制热、自动、除湿、目标温度和风速控制。
- 空调风速选项为“自动”和“1档”至“7档”，不显示高、中、低别名。
- 每台 VRF 室内机提供一个独立风扇实体，包含 7 个风速档位，并将“自动”作为
  预设模式。空调实体和风扇实体的状态保持同步。
- HTHM 空间制热控制不会中断正在运行的生活热水模式。
- 提供室内机和室外机的在线、故障及运行状态。
- 提供室外温度、运行模式、运行中室内机数量和已解析的故障代码。
- 使用连续批量读取减少 Modbus 通信量。
- 控制写入成功后立即更新 Home Assistant 本地状态，不主动读取设备状态。每个
  受控字段至少保持 15 秒乐观状态，保护期结束后由下一次定时轮询结果更新。

对于地址连续的 32 台室内机，每轮状态读取使用 5 次有界输入寄存器请求和 1 次
离散输入请求，每次寄存器请求不超过 120 个寄存器。集成不会为每台室内机分别
发起状态请求。

## 网关准备

1. 连接网关网口，打开 `http://192.168.1.185:8586`，这是出厂默认地址。
2. 为网关设置固定 IP，并配置唯一的 Modbus 地址。
3. 在 Home Assistant 中打开“设置 > 设备与服务 > 添加集成”，选择
   “Kaysun GW-Modbus(A)”。
4. 填写 Modbus TCP 地址和端口、网关 Modbus 地址以及室内机/室外机地址。

网关网页配置端口为 `8586`，Modbus TCP 通常使用端口 `502`。如果 Home
Assistant 运行在 Docker 中，请确保容器网络能够访问网关所在局域网。

## 地址约定

手册使用 `30001`、`45002` 等参考地址，而 Modbus 协议请求使用从零开始的地址：

- 室内机输入寄存器：`30001 + n*16` -> 协议地址 `n*16`。
- 室内机控制寄存器：`45002 + n*8` -> 协议地址 `5001 + n*8`。
- 室外机输入寄存器：`32001 + n*10` -> 协议地址 `2000 + n*10`。
- 室内机离散输入：`10001 + n*8` -> 协议地址 `n*8`。
- 室外机离散输入：`11001 + n*8` -> 协议地址 `1000 + n*8`。

控制写入按照手册要求使用功能码 `0x10`。部分室内机型号可能不支持全部运行模式
或风速档位，请根据实际设备能力配置温度上下限。
