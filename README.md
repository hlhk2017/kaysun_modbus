# Kaysun GW-Modbus(A) · Home Assistant 集成

面向 Kaysun `GW-MOD(A)` / `K05-MODBUS A` 网关的**本地 Modbus TCP** 集成，遵循手册 `MD20U-014A-ZH`（A.0 版）的寄存器映射，无需依赖云端。

## 主要功能

- **UI 配置**：全部通过界面完成，无需编写 YAML，支持修改选项。
- **多室内机**：室内机地址 `0-63`，支持连续或非连续地址（如 `0-7,10,12-31`）。
- **VRF 空调控制**：开关、送风、制冷、制热、自动、除湿、目标温度、风速（自动 + 1–7 档）。
- **独立风机实体**：每台室内机一个风机实体，7 档风速，Auto 作为预设，与空调控制保持同步。
- **HTHM 采暖**：空间采暖控制，不打断正在进行的制热模式。
- **状态监测**：室内/室外机在线、故障、运行状态，室外温度、运行模式、活动室内机数量及故障码解析。
- **高效轮询**：连续批量读取，减少 Modbus 通讯压力。

## 配置方式

1. 连接网关 LAN 口，浏览器打开 `http://192.168.1.185:8586`（出厂默认）进行网关设置。
2. 为网关分配固定 IP，并设置唯一的 Modbus 地址。
3. 在 Home Assistant 打开「设置 → 设备与服务 → 添加集成」，选择 **Kaysun GW-Modbus(A)**。
4. 填写 Modbus TCP 主机/端口、网关 Modbus 地址以及室内机/室外机地址。

## 注意事项

- 网页配置界面使用端口 `8586`，Modbus TCP 通常使用端口 `502`。
- 若 Home Assistant 运行在 Docker 中，容器需要能够路由到网关所在局域网。
- 手册中的参考地址为 `30001`、`45002` 等，Modbus 协议地址从 0 开始，集成已做换算。
- 部分室内机型号不支持全部模式或风速，请按实际设备设置温度上下限。
- 依赖 Home Assistant 自带的 Modbus 集成所提供的 pymodbus 版本，无需额外安装依赖。

## 安装

### 方式一：HACS（推荐）

1. 打开 HACS → **集成** → 右上角菜单 → **自定义仓库**。
2. 添加仓库地址 `https://github.com/hlhk2017/kaysun_modbus`，类别选择 **Integration**。
3. 在 HACS 中搜索并安装，然后**重启 Home Assistant**。
4. 到「设置 → 设备与服务 → 添加集成」搜索对应集成名称进行配置。

### 方式二：手动安装

1. 下载或克隆本仓库。
2. 将 `custom_components/kaysun_modbus` 整个目录复制到 Home Assistant 配置目录的 `custom_components/` 下。
3. 重启 Home Assistant，再在「设置 → 设备与服务 → 添加集成」中添加。
